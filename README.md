# Phoenix Downloader

Android video downloader. Paste a link, pick quality, download.

## Features

- Download from YouTube, Facebook, TikTok
- Up to 4K quality (MP4) + audio extraction (MP3/M4A)
- Full in-app browser with account login support
- Multi-connection downloads, 3 concurrent files
- Bilingual: Myanmar + English

## Engine

Powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp). The app auto-updates the yt-dlp binary from GitHub Releases — no app update needed for extractor fixes.

## Download

Get the APK from [Releases](https://github.com/myokooo2004/Phoenix-Downloader/releases). No Play Store.

## Build

Standard Android Gradle build. `yt-dlp` binary + `aria2c` bundled per ABI.
